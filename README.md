# Notes App Backend

A simple and efficient backend for a notes-taking application. This project focuses on CRUD operations and database management using the MERN stack.

##  Features
- **Create Notes:** Save thoughts with a title and description.
- **Read/View:** View all saved notes dynamically.
- **Persistent Storage:** Integrated with MongoDB for data reliability.

##  Tech Stack
- **Node.js** & **Express.js** (Backend Framework)
- **MongoDB** & **Mongoose** (Database & Modeling)

##  How to Run Locally
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Create a `.env` file and add your `MONGO_URI`.
4. Run the server using `npx nodemon server.js`.
